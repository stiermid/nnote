# nnote documentation

## Commands

- [`new`](commands/new.md) — create a note (or a subdirectory)
- [`view`](commands/view.md) — print a note to stdout
- [`edit`](commands/edit.md) — open an existing note in the editor
- [`list`](commands/list.md) — display notes as a tree
- [`drop`](commands/drop.md) — remove a note or directory
- [`move`](commands/move.md) — rename or relocate a note
- [`backup`](commands/backup.md) — export notes to a `.tar.gz` archive
- [`search`](commands/search.md) — search notes by title and content
